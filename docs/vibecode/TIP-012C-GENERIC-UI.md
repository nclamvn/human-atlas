# TIP-012C — Generic catalogue and player UI

## Objective

Replace bespoke entry/player markup with a reusable Vietnamese cinematic tour interface.

## Deliverables

- Metadata-only tour entry card.
- Generic chapter rail, narrative panel, evidence disclosure, pager and recovery UI.
- Keyboard navigation, focus states, reduced-motion and responsive mobile behavior.

## Acceptance criteria

1. Female Abdomen retains five-beat content and accepted interaction hierarchy.
2. All controls are keyboard reachable and have Vietnamese accessible names.
3. Evidence level is conveyed in text, not only color.
4. Desktop 1280×720 and mobile 390×844 remain legible without overflow.

Dependencies: TIP-012B. Priority: P0.
